# AppuHami Web - A GPT3 Client (pre-ChatGPT era)

AppuHami was a web app I developed during my first year at university when GPT-3 was still emerging technology. The project aimed to create a tool that could automate common tasks, such as generating speeches, converting text formats, and more, by leveraging GPT-3.

The core idea was to make everyday academic tasks easier and more efficient. I built a simple yet functional interface that allowed users to select from a list of tasks, like generating essays or fixing text formatting, and then execute these tasks with just a few clicks.

The app was hosted on Firebase, making it easily accessible to friends and colleagues. Despite being a basic app, AppuHami quickly became popular among peers, helping with assignments and research projects.
