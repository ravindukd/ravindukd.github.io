# Official Blog of Rotaract Club of Uva Wellassa University

Rotaract Club of Uva Wellassa University — Website & Blog Platform

I first joined the Rotaract Club as a member of the web team and worked on building the backend for the club’s blog platform using Laravel. Together with the development team, we launched the club’s official website under the domain racuwu.com.

Later, I was appointed as the Co-Director of Public Relations and Digital Services Avenue. In this role, I formed a new development team to continue improving the platform. One of the main upgrades was the migration from racuwu.com to racuwu.lk, along with a full content and feature update.

Since the club already had an active Blogger site with published articles, we decided not to disrupt the content workflow. Instead, we integrated the Blogger API into the new Next.js frontend, allowing the website to load posts directly from the existing Blogger dashboard. This allowed the content team to keep using a familiar interface while the public site received a modern UI and improved performance.

Key work done:
- Backend development using Laravel
- Website setup, hosting, and domain transition
- API integration to sync external blog content
- Team coordination and task planning as co-director
- Continuous updates based on club needs and feedback

Website Link: https://racuwu.lk

This project gave me experience not only in development, but also in leading technical projects, managing a team, and building tools that work smoothly for both developers and non-technical users.
